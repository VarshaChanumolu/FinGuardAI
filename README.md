# FinGuard-AI: Self-Optimizing Fraud Detection with Multi-Agent LLMs, RAG, and A/B Testing 

## Project Overview

FinGuard-AI is a complete fraud-detection system designed to adapt and improve continuously. It combines cutting-edge techniques:

-   **Groq API Integration**: Uses the high-speed Groq API for Llama 3.1 inference, ensuring real-time reasoning without local hardware constraints.
-   **Retrieval-Augmented Generation (RAG)** for enhanced narrative explanations.
-   **Multi-Agent Architecture** for modular detection and explanation pipelines.
-   **Continuous Experimentation (A/B Testing)** using multi-armed bandits (Thompson Sampling) to optimize reasoning strategies in real-time.

The system aims to generate dual-mode explanations, reduce false positives, and improve detection accuracy through a production-ready solution with interactive visualizations and automated evaluation.

## Features

-   **High-Speed LLM**: Integrates Llama 3.1 via the Groq API for fast detection and narrative generation.
-   **Multi-Agent System**: Orchestrates detection, explanation, and evaluation.
-   **A/B Testing with Thompson Sampling**: Dynamically optimizes reasoning strategies.
-   **Dual-Mode Explanations**: Provides both numeric risk breakdowns and coherent narrative justifications.
-   **Continuous Learning**: Adapts to outcomes to improve accuracy and reduce false positives.
-   **Interactive Dashboard**: A Streamlit application for real-time monitoring and review, with pause/resume and dataset selection.
-   **Containerized Deployment**: Docker support for easy setup and reproducibility.

## System Architecture

The FinGuard-AI system comprises several interconnected agents:

1.  **A/B Experiment Agent**: Uses Thompson Sampling to assign incoming transactions to different reasoning variants.
2.  **Detection Agent**: Classifies transactions using either pure LLM reasoning (from the Groq API) or a hybrid approach combining the LLM with dataset-specific expert rules.
3.  **Explanation Agent**: Generates justifications for flagged transactions, offering a numeric breakdown or a RAG-enhanced narrative generated by the Groq API.
4.  **Evaluator Agent**: Computes performance metrics (precision, false positives) and sends rewards back to the A/B agent to update variant selection probabilities.

## Setup and Installation

### Prerequisites

-   Python 3.9+
-   pip (Python package installer)
-   **Groq API Key**: A free key from the Groq console.
-   Docker (optional, for containerized deployment).

### Local Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/FinGuard-AI.git
    cd FinGuard-AI
    ```

2.  **Create a virtual environment (recommended):**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows: `venv\Scripts\activate`
    ```

3.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Set up Groq API Key:**
    *   Go to [https://console.groq.com/keys](https://console.groq.com/keys) to get your free API key.
    *   Create a file named `.env` in the root directory of the project.
    *   Add your Groq API key to the `.env` file:
        ```
        GROQ_API_KEY="gsk_YOUR_GROQ_API_KEY_HERE"
        ```
    Replace `"gsk_YOUR_GROQ_API_KEY_HERE"` with your actual key.

### Data Sources

The project uses two types of data, located in the `data/` and `rag/` subfolders:

-   **Transactional Data**: CSV files (`card_transdata.csv`, `creditcard.csv`, `paysim.csv`).
-   **Narrative Data**: PDF files (`2024-19260.pdf`, `USCODE-2023-title31.pdf`) used by the RAG system.

## Running the Application

### Running Locally

1.  **Ensure all dependencies are installed** and your **Groq API Key is set** in the `.env` file.
2.  **Start the Streamlit application:**
    ```bash
    streamlit run app.py
    ```

    **Using the UI:**
    *   **Select Dataset**: Use the dropdown in the sidebar to choose which transactional dataset to run.
    *   **Start / Resume**: Click to begin or continue the simulation.
    *   **Stop**: Click to pause the simulation and examine the current results.
    *   **Reset Simulation**: Clears all simulation progress.

### Running with Docker

1.  **Build the Docker image:**
    ```bash
    docker build -t finguard-ai .
    ```

2.  **Run the container:**
    You must mount the data directories and pass your `GROQ_API_KEY` as an environment variable.
    ```bash
    docker run -p 8501:8501 -v $(pwd)/data:/app/data -v $(pwd)/rag:/app/rag -e GROQ_API_KEY="gsk_YOUR_GROQ_API_KEY_HERE" finguard-ai
    ```
    (On Windows, you might need to use `%cd%` instead of `$(pwd)` for volume mounting.)

    Replace `"gsk_YOUR_GROQ_API_KEY_HERE"` with your actual key.
